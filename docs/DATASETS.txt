DATA ACQUISITION NOTES
----------------------

- For automatic download at runtime, use a server-side data fetcher with
  proper caching (Zarr/Dask) so the browser only receives subsetted slices.
- For real-time data, set up an OPeNDAP server or use COPERNICUS MARINE Toolbox.
- For INCOIS-specific operational data, coordinate with INCOIS data management
  group for access credentials.
