TECH STACK
==========

FRONTEND (earth-globe)
----------------------

Core
- React 19.2
- TypeScript 6
- Vite 8.2

3D Rendering
- Three.js 0.185
- @react-three/fiber 9.7 (R3F)
- @react-three/drei 10.7 (R3F helpers)

Lint / Build
- oxlint
- tsc -b (type-check gate before vite build)

UI
- Hand-written components (no heavy UI library)
- Small shared UI kit (src/components/ui: theme, icons, shared types)
- URL-parameter driven state (no global store)

Core

- FastAPI 0.115

Data
- NumPy 2.1

HTTP / Async

DEPLOYMENT
----------

- Docker (backend image only)

- Uvicorn (backend)

WHY THESE CHOICES
-----------------

- Three.js + R3F: Best-in-class WebGL with React ergonomics
- FastAPI: Async, modern, auto OpenAPI docs
- Pydantic v2: Strong typing + JSON schema
- NumPy + xarray: Industry standard for scientific computing and NetCDF
- Vite: fast dev experience and build
- No heavy chart/UI library: keeps the bundle small and the look deliberate
- URL-param state: deep-linkable, testable dashboard panels
