# INCOIS Ocean Explorer — Portable Project Bundle

Complete, self-contained source for the **INCOIS Ocean Explorer** SIH 2026
project: interactive 3D earth model (frontend) + FastAPI data API (backend) +
real ocean data + docs. Everything is included for a clean local run and later
merge.

**Bundle layout**
```
earth-model/
├── frontend/            React 19 + Three.js interactive globe (run this)
├── backend/             FastAPI data API (currents + waves)
│   ├── app/             API routes, adapters, services
│   └── data/model_db/   real data: GODAS NetCDF + WW3 wave snapshot
├── docker/ , docker-compose.yml   backend Docker build
├── scripts/             real-data fetch pipelines (WW3)
├── docs/                architecture, data sources, deployment, demo script
└── README.md            this file
```

The frontend visualizes data served by the backend. Start the backend first.

---

## 1. Run the backend (port 8000)

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Verify: http://localhost:8000/api/health → `{"status":"online",...}`
API docs: http://localhost:8000/docs

Real data ships in the bundle, so currents (`/api/data?dataset=godas_indian_ocean`)
and waves (`/api/wave`) work immediately — no downloads needed.

---

## 2. Run the frontend (port 5173)

```bash
cd frontend
npm install
npm run dev                        # http://localhost:5173
```

The frontend reads the API from `VITE_GODAS_API` (defaults to
`http://localhost:8000`). If your backend runs elsewhere, create
`frontend/.env.local` with:

```
VITE_GODAS_API=http://localhost:8000
```

---

## 3. Docker (optional, backend only)

```bash
docker compose up --build            # backend on :8000
```

---

## 4. Production build (frontend)

```bash
cd frontend
npm run build                        # tsc -b && vite build → dist/
npm run preview
```

## What your friend should know

- **node_modules / dist / .venv are intentionally excluded** — regenerated by
  `npm install` / `pip install` above. Do not commit them.
- **Keep `backend/data/model_db/` intact** — it holds the real GODAS + WW3 data
  the layers need.
- Frontend URL params drive the demo panels: `?anim=waves&overlay=waves`,
  `?time=manual&t=450`, `?cl=0`, `?ar=1` (slow auto-rotate). See
  `frontend/docs/PROJECT_STRUCTURE.md` for the full reference.
- To merge later: keep `frontend/` (globe + UI) and `backend/` (API + data)
  as sibling directories and preserve `docs/`.

## Real data provenance

- **GODAS** — NCEP Global Ocean Data Assimilation System reanalysis (real),
  depth-resolved NetCDF under `backend/data/model_db/godas/`.
- **WW3 waves** — NOAA/NCEP WAVEWATCH III global wave model (real), snapshot
  JSON under `backend/data/model_db/wave/`.
- **Coastlines** — Natural Earth 50 m, baked into `frontend/public/assets/...`.

See `docs/DATA_SOURCES.md` and `docs/ARCHITECTURE.md`.
